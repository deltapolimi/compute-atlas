# Compute Atlas

An open map of the computing power behind AI: where it is, how much there is, and who owns it.
A [DeLTA](https://deltapolimi.org) student project at Politecnico di Milano.

**Brief:** https://deltapolimi.org/projects/compute-atlas/
**Project lead:** Ermanno di Giulio

## What we're building

Sources → ETL → Database → REST API → Website

- **Data:** AI data centers and GPU clusters (Epoch AI), cloud regions of the main providers,
  ownership chains (GLEIF, Wikidata).
- **Platform:** REST API and website with search, entity and country pages, and a map.
- **Rule:** every record has a source and a last-updated date.
